# Windows / Mac：交付到客户能自己使用

[安装清单](installation-checklist.md) · [项目示例](project-example.md)

供 FDE 规划、检查和交接使用。本 Skill 运行器仍只执行 Windows 项目内合成示例；以下真实目标步骤是交付验收要求，不触发远程连接或系统安装。

## 先把完成条件写清楚

- [ ] 写明目标用途、系统与架构、本机或另一台、所选 Agent、第一件任务和验收人。
- [ ] 每项记录：待确认 / 进行中 / 通过 / 待完成；证据区分工具观察与使用者确认。前一项通过不能自动勾选后一项。
- [ ] 客户只处理当前必要的一步。地址用于选择目标、公钥指纹用于核验身份；不向客户索要密码、PIN、API Key、订阅、完整网络配置或旧聊天。

## 按系统准备交接

| 检查环节 | Windows | Mac |
|---|---|---|
| 身份与位置 | 实际账户、系统、原生或 WSL、当前目录 | 实际短账户、macOS、Apple 芯片或 Intel、目录 |
| 另一台电脑的首轮交接 | 规划目标端只读小助手与明确授权；PIN 不能直接作为 SSH 密码 | 规划目标端小助手；远程登录仅限所选用户，无需屏幕共享或磁盘完全访问 |
| 连接完成条件 | 独立指纹一致、认证、身份、退出后重连分别留证据 | 同样逐项核验，端口开放不算认证成功 |
| 已有环境 | 原生与 WSL 工具、路径、服务分开，不为清单重装 | 先核对用户级安装和 NVM；不在 PATH 不代表不存在 |
| 可用交接 | 实际可执行位置、打开入口、模型配置状态、本人试用 | 实际前缀、可点击启动或原生入口、本人试用 |
| 临时授权收回 | 只撤本次精确授权，保留其他公钥/ACL/服务，重新认证应被拒绝 | 同样保留既有授权与服务；到期不等于已经结束运行中的命令 |

真实连接和安装交由客户已有且获授权的执行工具完成。本 Skill 整理步骤、范围、证据与缺口；不将客户授权资料、主机指纹、专用 ZIP 或原始日志写入公共材料。

## 安装、加载、成果分别验收

- [ ] **安装：** 核对来源、确切版本、系统/架构、真实目录与可执行文件；网络中断先确认状态与包完整性，再接续，不能执行半个下载包。
- [ ] **启动：** 告诉客户装在哪里、怎么打开、怎么退出；由本人在目标打开。命令行版本成功不能代替可用入口。
- [ ] **模型：** 客户在目标原生界面输入账户凭据；只记录已配置与可用状态。
- [ ] **规则：** 只合并明确选择的 AGENTS.md 等行为规则，不搬 SOUL、USER、记忆、聊天；用实际加载与行为检查验收，工具权限另外检查。
- [ ] **Skills：** 只装任务需要且审阅过的技能，核对发现、加载、调用和输出；已有定制保留。
- [ ] **成果：** 新建不含私人数据的测试任务，由客户判定结果；记录工具观察或客户确认，不虚构输出。
- [ ] **安全：** 功能结果与安全待办分开；改变已有应用权限需具体授权。临时授权撤销后验证新登录被拒绝，超时不能作拒绝证据，再清理本次密钥。
- [ ] **接续：** 私有记录保留代号、来源/版本/摘要、具体变更、恢复方法、未完成项和下一条 check。公开材料仅保留脱敏范围与结果。

## 已验证经验怎样用于下一次

2026-10 的一次 Windows 实例完成了临时 SSH 全流程、复用现有 OpenClaw 的健康与合成任务；一次 Apple 芯片 Mac 实例完成临时 SSH 全流程、用户级新装 Node/OpenClaw 和 CLI 核验，使用者随后确认验证成功。两次临时授权均撤销并验证拒绝新登录。

这些实机经验用于完善上述交付条件，不代表本项目运行器已支持真实客户部署，也不代表任意版本、Intel Mac、规则/Skill 加载或手机渠道都已通过。新客户仍按自己的环境与任务独立验收。
