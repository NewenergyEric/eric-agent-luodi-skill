# 落地 · luodi：Windows / Mac，一套交付流程

24 秒中文蓝色短片，以连续纸面转场串起从电脑准备到后续维护的六个环节。

| 时间 | 主文案 | 画面内容 |
|---|---|---|
| 0–3.6 秒 | Windows / Mac，一套交付流程。 | 选择系统、Agent 和第一件客户任务 |
| 3.6–7.6 秒 | 先选系统，再核对环境。 | Windows 看运行方式；Mac 看系统、芯片、终端和目录权限 |
| 7.6–12 秒 | 沿用已有效的，按需补齐缺口。 | 复用已有工具，核对版本，审阅配置差异 |
| 12–15.8 秒 | 第一项工作，要有具体成果。 | 原创任务示例：会议纪要转行动清单，列出负责人、期限和需补充的信息 |
| 15.8–20.4 秒 | 安装到结果，分别验收。 | 检查环境、运行器、行为规则、Skills、任务成果与客户配置 |
| 20.4–24 秒 | 技能继续加，客户定制留下。 | 保留版本、证据和下一步，从 check 开始接续 |
