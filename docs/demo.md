# 落地 · luodi：Windows / Mac，一套交付流程

24 秒中文蓝色短片，沿用字体、配色与连续纸面转场。Windows 和 Mac 都是准备流程的主要入口；完整部署仍是产品目标，流程支持不等于实机安装通过。

| 时间 | 主文案 | 画面与证据性质 |
|---|---|---|
| 0–3.6 秒 | Windows / Mac，一套交付流程。 | 明确双系统，选择 Agent 和第一件任务；输入示意 |
| 3.6–7.6 秒 | 先选系统，再核对环境。 | Windows 看实际运行方式；Mac 看 macOS、芯片、终端和目录权限 |
| 7.6–12 秒 | 沿用已有效的，按需补齐缺口。 | 优先复用已有工具，按差异准备；安装适配仍待接入 |
| 12–15.8 秒 | 第一项工作，要有具体成果。 | 合成会议纪要转行动清单，包含负责人、期限与待确认项；未经 Agent 实跑 |
| 15.8–20.4 秒 | 安装到结果，分别验收。 | Windows 示例与 Mac 引导分支已验证；Mac 实机执行和真实 Agent 加载另列待办 |
| 20.4–24 秒 | 技能继续加，客户定制留下。 | 双系统都记录版本、结果与待办，下一段对话先 check |

Mac 准备流程覆盖系统与芯片、终端和权限、依赖与网络、IDE/Agent、行为规则、Skills、任务验收；Windows 沿用同一顺序，按实际运行方式核对。详见[七步清单](installation-checklist.md)与[分系统准备](computer-guide.md#系统准备与验收)。

Windows 的真实本地基础见 [system-guide-evidence.json](system-guide-evidence.json) 和[隔离验证](installation-verification.json)。Mac 引导逻辑在 Windows 上用合成输入验证，Mac 实机仍待验证。参考搭好的 Windows 接入顺序时，不继承其他目标的授权或运行结果。

任务示意的[会议纪要](../examples/first-task/meeting-notes.md)与[行动清单](../examples/first-task/action-list.md)由作者编写。画面进度条只表示影片播放位置，没有模拟安装成功或虚构真实任务验收。
