# 落地 · luodi 中文影片：让新电脑里有一个能干活的 Agent

24 秒蓝色流程片。沿用原字体、深蓝/青绿/薄荷色及连续纸面转场；本次仅更新中文影片。完整部署仍是目标流程，不能据此宣称运行器已安装或加载。

| 时间 | 主文案 | 画面与证据性质 |
|---|---|---|
| 0–3.6 秒 | 一台新电脑，配成 Agent 工作机。 | 选择 Mac/Windows、所需 Agent、第一项工作；目标输入示意 |
| 3.6–7.6 秒 | 先选系统，再核对环境。 | 已实现的只读目标分流、环境元数据及包来源核对；同时显示安装缺口 |
| 7.6–12 秒 | 备齐环境，配好 Agent。 | 依赖、Agent、Skills 部署规划；安装适配明确待接入，不模拟安装进度 |
| 12–15.8 秒 | 第一项工作，要有具体成果。 | 合成会议纪要转带负责人、期限和待确认项的行动清单；尚未经 Agent 实跑 |
| 15.8–20.4 秒 | 安装到结果，分别验收。 | 分别显示已验证的本地基础与未接入的运行器/业务任务 |
| 20.4–24 秒 | 技能继续加，客户定制留下。 | 配置/检查/更新、客户覆盖独立保存、交付回执与下次接续 |

主文案：从一台新 Mac 或 Windows 电脑开始，确定客户要用的 Agent，检查环境与依赖，按可审查的计划配置运行器和 Skills，再用第一项具体工作验收。交付后继续添加、更新技能，保留客户的定制，并让下一段对话接着维护。

任务示意的[输入](../examples/first-task/meeting-notes.md)与[行动清单](../examples/first-task/action-list.md)由作者编写，没有调用真实部署的 Agent；待办没有被标为已完成。

真实基础证据见 [system-guide-evidence.json](system-guide-evidence.json)：Windows 项目内配置包、幂等重跑、覆盖保留、更新和失败恢复，以及只读系统/接入分流。Mac 实机执行、依赖安装、Agent 安装与加载、客户真实任务均未验证。底层测试数据只用于工程验证，不作为影片的业务叙事。

影片全程标注“目标流程演示 · 真实 Agent 安装未接入”。进度条只表示影片播放位置，不是部署进度。没有虚构终端安装或安装完成绿勾。
