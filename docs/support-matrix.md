# 系统与运行器支持矩阵

“能生成该分支的引导计划”与“已支持该目标执行”分开报告。

| 能力 | Windows | Mac | 当前证据与边界 |
|---|---|---|---|
| 需求、目标、接入分流 | 已实现只读计划 | 已实现只读计划 | 单元测试验证分支；Mac 分支在 Windows 模拟输入测试，未上 Mac 执行 |
| 项目内固定示例包配置/更新 | 已实测 | 未实现/未实测 | Windows 标准库引擎及合成任务 |
| 重复执行、覆盖保留、漂移、恢复 | 已实测示例路径 | 未实现/未实测 | 不推广到未接入的系统或运行器 |
| 环境探测 | 本机 OS / Python / PATH 与版本元数据 | 尚无完整预检适配 | 不代表依赖已安装或运行器健康 |
| 依赖自动安装 | 未实现 | 未实现 | 需要固定来源、版本/hash、权限及恢复配方 |
| 网络诊断 | 未实现 | 未实现 | Clash 仅本机可选工具探测；不读取订阅或改网络 |
| 另一台电脑接入 | 引导与缺口提示 | 引导与缺口提示 | 不建立连接，不验证远端，不持久化访问 |
| Codex / OpenClaw / Hermes | 只读版本探测；安装待配置 | 未接入 | 没有运行器安装/服务控制/激活适配 |
| 真实 Skill 加载与用户任务 | 未验证 | 未验证 | 当前本地脚本验收仅为合成示例 |

## 最小接入顺序

1. 选定**一个系统、一个目标、一个运行器及明确版本、一个真实任务**，确认对应执行授权。优先本机，已有执行器不为配置另启 SSH。
2. 实现该系统的只读预检和依赖/网络检查，输出证据与阻塞项。固定安装来源和 hash，不用动态“最新版”替代版本契约。
3. 实现一个依赖安装配方和一个运行器安装适配：计划、具体差异、权限、前镜像、恢复动作、安装后版本检查。不能自动把别处的密钥或上下文搬过来。
4. 接入真实 Skill 的放置、加载证据和一件用户任务；分别记录安装、加载与业务验收，复用覆盖/漂移/回执机制。
5. 在新的隔离环境验证冷启动、重跑、失败恢复与升级，再决定是否扩展另一操作系统或远端适配。

此顺序是待实现工作，不是已经支持的安装清单。仍保持三个用户入口，不引入服务端、数据库或常驻管理平台。
