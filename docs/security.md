# 安全与隐私

落地的执行器面向 Windows 项目内合成示例。Windows / Mac 清单用于准备和交付规划；具体执行范围见[支持矩阵](support-matrix.md)。

## 提交问题和贡献

- 使用新建合成示例复现，提供最少的版本、步骤、错误代码与预期行为。
- 不在 issue、PR、截图、日志或附件中粘贴 token、订阅链接、私钥、cookie、账户口令、真实目标地址、客户文件或聊天。
- 只合并用户明确选择的配置键，凭据只用引用；不把私人规则、记忆或整份用户配置复制进项目。
- 怀疑已经泄露凭据时，先由凭据所有者撤销或轮换；删除当前文件不能消除 Git 历史或既有下载副本。

## 报告漏洞

如仓库 Security 页提供 **Report a vulnerability**，请通过该私密入口报告。不要在公开 issue 中发布利用细节或敏感样本；入口不可用时，只用 issue 请求建立私密报告渠道。

## 发布检查

运行 `python -B tools/release.py check`，再审阅完整远端 Git 历史和 GitHub 附件、日志。所有公开文件逐项列入 `release-files.json`；本地私有目录、计划、回执、客户数据、原始渲染目录和 node_modules 不打包。

源码检查、敏感模式扫描、媒体审阅与测试共同提供审查依据，不能证明未来新增内容绝对安全。媒体源码、来源声明和许可随项目保留，便于其他维护者继续复核。
